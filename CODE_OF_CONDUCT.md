# Code of conduct

toolvet is a small project and I want it to be a pleasant place to contribute. The rule is
simple: treat people the way you would want to be treated in a code review.

## What is expected

- Be respectful and assume good faith. Disagree with the idea, not the person.
- Be specific and constructive when reviewing, and graceful when your own work is reviewed.
- Welcome newcomers. Everyone here started out not knowing the codebase.
- Keep to the topic of the project in issues and pull requests.

## What is not acceptable

- Harassment, insults, personal attacks, or discriminatory language or jokes.
- Publishing someone else's private information.
- Sustained disruption of discussions, or repeated unwanted contact.

## Scope

This applies in the repository: issues, pull requests, discussions and reviews. It also applies
when someone is representing the project elsewhere.

## Enforcement

The maintainer may edit or remove comments, close or lock issues and pull requests, and block
people from the repository, when that is needed to keep it a respectful place.

To report a problem privately, use GitHub's private report form (the repository's Security tab,
"Report a vulnerability") and start the title with "Conduct:". It reaches only the maintainer.
Reports are treated confidentially.
